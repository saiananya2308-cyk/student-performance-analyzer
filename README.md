# Student Performance Analyzer

## About the Project
The Student Performance Analyzer is a Python-based project that analyzes students' marks and generates a performance report.

It uses Python concepts such as lists, dictionaries, loops, conditional statements, and functions.

## Features
- Calculates average marks.
- Finds the highest and lowest marks.
- Identifies all students sharing the highest marks.
- Identifies all students sharing the lowest marks.
- Counts the number of students who passed and failed.
- Generates a student performance report.

## Technologies Used
- Python

## Concepts Practised
- Variables and data types
- Lists and dictionaries
- For loops
- If-else conditions
- Functions
- List methods such as `append()` and `clear()`

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project file.
4. Run `student_performance_analyzer.py`.
